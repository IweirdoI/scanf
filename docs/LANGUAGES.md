# 多语言项目分析

同一项目可同时包含 TypeScript、JavaScript、Python、C、C++、Java、Rust 和 Go。扫描只建立一份源码快照、一张项目图；文件树不分语言，逻辑入口树保留各文件中的入口证据。选择文件时编辑器自动切换语法高亮，参数证据、搜索、调用树、全文阅读和版本校验复用同一套接口。

## 统一架构

`languages.ts` 集中声明扩展名、VS Code 语言 ID、函数与调用节点。`project-analyzer.ts` 编排解析结果：TS / JS 保留编译器符号解析，其他语言使用一个 `syntax-analyzer.ts` 共享提取器。提取器读取节点字段、声明作用域、参数、注释、源码位置和直接调用，再解析有明确依据的同语言关系。新增语言需要语法配置与少量模块 / 入口规则，不复制整个扫描器、项目图或窗口。

Tree-sitter 能统一读取语法结构，但不能统一替代所有编译器的类型、模块和构建规则。关系不足以确定目标时保留为未解析，不按整个项目的同名函数猜测。

## 已支持的语法与关系

- **TS / JS**：`.ts .tsx .mts .cts .js .jsx .mjs .cjs`；沿用 TypeScript Compiler API 的符号、路径别名、重导出、方法、参数和 JSDoc 分析。
- **Python**：`.py .pyi`；函数 / 方法、嵌套函数、类型标注、默认值、docstring、`:param` 注释和 `__main__` 守卫。支持扫描范围内的本地绝对 / 相对导入、别名和直接调用；不执行包初始化、装饰器或动态导入。
- **C / C++**：`.c .h .cpp .cc .cxx .hpp .hh .hxx`；函数定义、参数、注释、同文件直接调用和本地 include 依赖。`.h` 默认按 C 读取。宏不展开，不读取编译数据库，不跨翻译单元推断链接；函数指针调用不当作同名直接调用。
- **Java**：`.java`；方法 / 构造器声明、类型与参数注释、同一类中可唯一确定的直接调用、显式包导入依赖，以及常见 `public static void main(String[] args)` 入口候选。重载、继承、实例分派和构建源集不做完整类型求解。
- **Rust**：`.rs`；函数 / impl 方法、参数、文档注释、main 候选、显式 mod 与简单 use 别名。暂不完整解析 Cargo workspace、use 树、trait 分派、宏展开和 cfg 条件。
- **Go**：`.go`；函数 / 方法、分组参数、注释、package main 的 main 候选，以及同目录同包中唯一的自由函数调用。接收器方法不冒充包函数；go.mod 模块路径、build tags 和接口分派仍可能未解析。

其他语言的部分声明、匿名函数或特殊语法可能只显示在完整源码中。语法错误保留警告，不因成功打开文件就声称完成语义分析。结构步骤展示分支 / 循环 / return 等源码节点，不代表实际执行顺序。

## 混合项目与跨语言调用

前端 TS + Python 服务 + Go 工具可以一起展开、查符号、读源码和查看各自的入口。语言标记随符号与阅读快照返回，各宿主复用相同结果。

HTTP / RPC、子进程、JNI / FFI / PyO3 等跨语言桥接尚未建立可验证的调用匹配。两边函数即使同名，也不会自动相连；未解析调用仍可交给 Agent 结合源码解释。后续可通过同一项目图中的桥接证据扩展，无需重写界面。

## 安装、资源与验证

WASM 语法随 VSIX、DSH、MCP 和 Agent 包离线分发，按遇到的语言加载并缓存，不需要安装各语言编译器。Python / C / C++ / Java / Rust / Go 共用解析运行时，不安装六套语言服务。共享默认预算为 150 文件、每文件 256 KiB、总共 8 MiB；超过范围有提示。扫描跳过依赖、虚拟环境、缓存和构建目录；不是全仓无界索引。

测试覆盖八语言同图、Unicode 偏移、参数遮蔽、本地导入、Go 同包、Rust use、C 函数指针、Java 重载保留未解析，以及没有 node_modules 的 MCP 包。`examples/polyglot` 是独立语言样例集合，用于验证混合目录；这些样例之间没有实际跨语言服务调用。
