# DSH 自动代码阅读

安装插件后，在已有项目会话中打开右侧栏的 **Scanf 代码阅读**，直接显示当前会话项目的树与源码。不需要启动终端、不需要填写本机地址。默认会话没有源码或要阅读其他目录时，点击“切换项目”填写项目文件夹；这个选择会按会话记住。

后台通过 DSH 的认证 Connection 路由，读取 sessionPersistence 中当前会话的 cwd；按规范化目录复用本机阅读服务。会话切换时重新连接，失败显示原因与重试。服务使用随机端口和随机令牌，插件卸载时统一关闭；只允许本机同设备阅读。

小窗展示树与代码预览；展开工作台使用宿主浮动窗口，返回小窗重新停靠。宿主编辑器打开会定位到当前文件行。

构建：在 Scanf 项目根目录执行 `npm run build`。Host bundle 内含分析器，HTML 随包分发。DSH 插件通过原有本地 link 安装保持更新；首次从旧版迁移后台接口时可能需要重新启动 DSH。

自动流程测试覆盖当前会话目录、同目录并发复用、未知会话拒绝、HTTP 凭据、插件卸载关闭服务。原生宿主验收结果见主项目接入说明。

## 自选模型与悬停注释（0.6）

阅读器右上角星光图标进入“模型设置”，填写 OpenAI 兼容 API 地址、模型名、Key。后台使用 DSH credentials 的独立 SCANF_READER_MODEL 条目保存；不复用 DSH 的聊天模型或聊天 Key。测试连接、保存、清除配置均在面板内完成。配置后在 Scanf 源码词语上悬停，显示注释与模型解释，也可点击“模型解读”解释当前函数。没有对 DSH 自带的独立文件预览注入悬停功能。

VS Code 原生提供器与 DSH Scanf 阅读器均通过本机模拟 API 完成接线验证；真实服务商需用户自行填写配置测试。
